## Environment and implementation

The initial repository contained no application or commits. The user's specification package was
copied from the supplied B: folder and read before implementation. The initial session observed
SDK 10.0.302; the resumed session had SDK 10.0.401 installed. `global.json` pins the latter exactly.

then started locally. No AWS credentials/accounts/resources were used.

are centralized and each project has a committed lock file. EF tool version is 10.0.10.

## Corrections found during verification

Windows-generated container certificate paths initially contained a backslash after `/run/lab`;
this caused FileNotFoundException at startup. A portable certificate-path helper and non-destructive
runtime-config refresh fixed it. All five hosts subsequently started and passed TLS checks.
The first manual ACL application removed child inheritance; it was restored from the restricted
parent. The shipped generation script sets the parent ACL before creating files.
An internal proxy-blocking endpoint initially used a dynamic service segment and lost route precedence
to YARP's literal service prefix. The real HTTP integration test caught 401 instead of 404. Explicit
literal service blockers fixed it, and the test then passed.

## Limits and pending work

The Windows browser/computer-use helper failed to initialize with
`windows sandbox failed: helper_unknown_error: apply deny-read ACLs`. No UI screenshot or browser
interaction result is claimed. SSR form markup, live HTTPS login/logout, cookie properties, and
prerendered account identity were verified by HTTP. Interactive circuit establishment, multi-user
browser behavior, revalidation/expiry timing, and complete UI E2E need browser verification in LAB-007.

No business entities/APIs, Outbox/Inbox, Saga, payment provider, sender, or queue consumer is implemented.
Payments/email are labeled as future durable simulations, not represented as successful operations.
Business schemas contain only a versioned infrastructure baseline; service domain EF migrations follow
their tasks. AC-02..24 business scenarios, AC-26 full circuit isolation, AC-28 full human operation UI,
and AC-30 AWS pause/start remain pending. No AWS/Neon deployment or cost validation is claimed.

PostgreSQL and the broker are local Docker infrastructure; this does not verify Neon provider role
inheritance, Fargate networking/memory, cloud TLS, IAM, or paid-resource shutdown. API JWT logout
revocation is not implemented; their lifetime is bounded to 15 minutes. The lab has one Gateway
replica; circuit affinity must be designed before scaling. Windows scripts are the supported local flow.
