## Findings resolved and limits

1. The first OpenTelemetry 1.14.0 restore failed NuGet vulnerability auditing. It was replaced with 1.17.0; no warning suppression was used and the final package audit is clean.
2. A diagnostic rerun with an overly short 90-second hang watchdog aborted the initial authorization matrix, which used a fresh validated TLS client for every request. The original unbounded-watchdog run had already passed. The fixture now reuses one client per test; per-request identity headers remain isolated. That diagnostic abort is not represented as a passing run.
3. Initial messaging regression: seven passed, one failed because the old caller's ten-second timeout collided with the ten-second quote limit plus caller TLS setup. The test now allows twenty seconds and Gateway's named per-user client forty seconds (covering configured quote limits up to thirty). Catalog's three-second attempt/default ten-second total limit did not change. The corrected full messaging suite and final Gateway SSR check passed.
4. Adding optional tracestate could have changed stored Inbox fingerprints. Null tracestate is omitted and fingerprint normalization excludes it; a compatibility test verifies old envelope serialization is preserved. Existing money/transport IDs are not regenerated.
5. Crash inspection leases originally needed an explicit reacquisition condition. Inspection now replaces receipts only after no active replay lease, including expiration after a crash; the dedicated persisted-lease test passes.
6. A final trace-helper invocation initially failed because explicitly selecting only the five host services for Compose did not start the stopped collector/viewer. The documented full-profile command includes them. They were explicitly started for the helper rerun; this was a local setup error, not a passing trace check or a business-service dependency failure.

No unresolved confirmed local implementation defect is recorded after these checks. Independent LAB-006 review has **not** run: readiness is for review, not a claimed independent PASS.
